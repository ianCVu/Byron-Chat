# Byron Chat
Byron Chat is a test release of Chipmunk Chat 2.0 (the final release). Byron Chat is a fast open-sourced version of them.
It's two miliseconds faster than Chipmunk 1.9 and Chipmunk 1.3, and has certain conditions that reduces lag and the need to erase the database. Unlike the other versions the test version is open-sourced, Chipmunk Chat left the version opened like that for suggestions and bug reports.
The release was simply more trusting. It was also left open to assure the user's safety of the project.
